# Handwritten notes — to add

Drop exported images/PDFs of your iPad notes into `docs/screenshots/` (or a
new `docs/notes/` folder), then either:

- Link them directly from this file, or
- Fold any useful content from them into `docs/architecture.md` or
  `docs/troubleshooting.md` where it fits, then delete this placeholder.

When handing this repo off to Cowork, mention that these notes still need
to be incorporated — Cowork can help transcribe key points from the images
into the relevant doc and merge them in rather than leaving them as raw
image dumps.
